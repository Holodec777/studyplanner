# План презентации к защите

## Слайд 1. Маяк — учебный планер

Веб-приложение помогает ученику планировать задания по предметам, следить за сроками и отмечать прогресс.

## Слайд 2. Проблема и решение

Задания и сроки легко теряются в заметках и переписках. В «Маяке» план, приоритет и статус задачи собраны в одном интерфейсе.

## Слайд 3. Пользователи и права

Ученик управляет собственными задачами. Администратор видит общий план и может назначить задачу ученику. API проверяет права на каждой операции.

## Слайд 4. Технологии

Python, FastAPI, SQLAlchemy, PostgreSQL, Alembic, HTML, CSS, JavaScript, pytest и Docker Compose.

## Слайд 5. Данные и API

Две связанные сущности: пользователь и учебная задача. REST API отвечает за вход, роли, список задач, создание, изменение, удаление и сводку.

## Слайд 6. Демонстрация

Войти как ученик, добавить задачу, найти ее поиском, изменить статус. Затем войти как администратор и назначить задачу ученику.

## Слайд 7. Проверка и запуск

Права и основные сценарии покрыты API-тестами. Для запуска достаточно выполнить `docker compose up --build` и открыть `http://localhost:8000`.
